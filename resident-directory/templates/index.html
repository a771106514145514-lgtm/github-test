住戶資料整理系統

整合 Excel／PDF／圖片中的住戶資料，統一格式方便搜尋

1. 連接 Google 帳號

尚未設定 Google API 憑證（credentials.json）。請先依 README.md 的步驟在 Google Cloud Console 建立 OAuth 用戶端，下載後放到 resident-directory/credentials.json，再重新整理本頁面。

尚未連接 Google 帳號，資料不會被讀取，直到您點擊下方按鈕並完成授權。

✅ 已連接 Google 帳號

2. 選擇資料夾並開始整理

貼上 Google 雲端硬碟資料夾的連結，或直接輸入資料夾 ID。程式會遞迴掃描該資料夾內所有子資料夾。

3. 搜尋 / 瀏覽資料
